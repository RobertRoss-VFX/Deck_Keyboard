# Deck Keyboard

A small on-screen keyboard for the Steam Deck in desktop mode.

On-screen keyboards for Linux are easy to find and hard to use on a Deck. With an external monitor, the usual ones either never type, or they take focus as soon as you touch a key. The address bar you just clicked is no longer active, so you cannot type into it. This one stays out of the way: it sits in the system tray, and keystrokes go to the window that is already focused.

It is for desktop mode only. It does not run inside Steam game mode.

## Install

Copy this folder to the Deck, open it in the file manager, and double-click **Install**. If the system asks whether to run it, confirm.

Leave the window open until it says **Done**. The first run needs Wi-Fi and can take a few minutes. If it asks for a password, type your desktop password in that window. The letters stay hidden. A brand-new Deck often has no password yet. Create one in System Settings, under Users, and run Install again.

The icon then stays by the clock, including after the next login.

## Use

Left-click the tray icon to show or hide the keyboard. Right-click the icon for size, opacity, and quit.

The blue background is half transparent. Keys stay solid so the labels stay readable. The tray menu can make the keys transparent too.

Shift applies to the next letter. Caps stays on. Hold a key to repeat it. `.com` and `@` are there for web addresses.

Labels match the **Polish (programmers)** layout and the US layout. If the Deck is set to the Polish typist layout, letters such as z and y will not match the keys. Switch the layout to Polish (programmers) in the KDE settings.

## Known limits

The window cannot be dragged yet. Desktop mode on the Deck ignores the usual way of moving a window. It stays where it first appears.
